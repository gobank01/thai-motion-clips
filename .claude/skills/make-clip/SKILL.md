# make-clip: บอกหัวข้อ → ได้คลิป

คลิป 1 ตัว = ฉาก 3 ฉาก (ฮุก → รายการ 3 ข้อ → ตัวเลขเด่น + ปิดท้าย) ยาวประมาณ 12–20 วินาที ทุกอย่างวาดด้วยโค้ด ไม่มีค่าเรนเดอร์ เสียค่าแค่เสียงพากย์ (หรือฟรีถ้าใช้ edge-tts)

ทุกคำสั่งรันจากโฟลเดอร์หลักของ repo นี้

## ขั้นตอน (ทำตามลำดับ)

### 1. ถามให้น้อยที่สุด
ถ้าผู้ใช้ให้แค่หัวข้อ ให้เริ่มทำเลย ไม่ต้องถามกลับ เดาส่วนที่เหลือเอง:
- กลุ่มคนดู: เดาจากหัวข้อ
- สไตล์: เลือกจากตาราง "เลือกสไตล์" ด้านล่าง แล้วบอกผู้ใช้ว่าเลือกเบอร์อะไร เพราะอะไร
- ปิดท้าย (`end`): ถ้าผู้ใช้ไม่ได้บอก ใช้คำกลางๆ เช่น "กดติดตามไว้เลย" หรือ "ลองทำวันนี้"
ถามกลับเฉพาะตอนหัวข้อกว้างจนเขียนไม่ได้จริงๆ

### 2. เขียนบท → `my-clips/<ชื่อสั้นภาษาอังกฤษ>/story.json`
ตั้งชื่อโฟลเดอร์เป็นภาษาอังกฤษตัวเล็กมีขีด เช่น `my-clips/coffee-shop-tips`

```json
{
  "kicker": "หัวข้อเล็กด้านบน",
  "hook": ["บรรทัดที่ 1", "บรรทัดที่ 2", "คำเด่น"],
  "list": { "title": "หัวรายการ", "items": ["ข้อ 1", "ข้อ 2", "ข้อ 3"], "at": [0.3, 0.5, 0.74] },
  "stat": { "label": "ข้อความเหนือตัวเลข", "num": 3, "unit": "หน่วย", "prefix": "" },
  "end": "คำปิดท้าย",
  "say": ["บทพูดฉากฮุก", "บทพูดฉากรายการ", "บทพูดฉากตัวเลข"]
}
```

กฎความยาว (เกินแล้วตัวหนังสือจะถูกย่อจนอ่านยาก):
- `hook` 3 บรรทัดพอดี: บรรทัด 1–2 ไม่เกิน ~18 ตัวอักษร บรรทัด 3 เป็นคำกระแทก ไม่เกิน ~8 ตัวอักษร
- `list.items` 3 ข้อพอดี ข้อละไม่เกิน ~14 ตัวอักษร · `list.title` ไม่เกิน ~12
- `stat.num` ต้องเป็นตัวเลข (นับขึ้นเอง) · `prefix` เช่น "฿" · `unit` เช่น "ชั่วโมง"
- `end` ไม่เกิน ~16 ตัวอักษร · `kicker` สั้นๆ
- `say` 3 ประโยค ตรงกับ 3 ฉาก ประโยคละ 2–5 วินาทีเมื่อพูด (ราว 15–45 ตัวอักษร) ใช้เป็นซับด้วย
- ถ้าเสียงอ่านคำไหนผิด (เช่น AI) ให้เพิ่ม `"speak": [...]` 3 ประโยค เขียนตามเสียงอ่าน เช่น "เอไอ" ซับยังใช้ `say`

กฎเนื้อหา:
- ห้ามแต่งตัวเลขสถิติหรือข้อเท็จจริงขึ้นมาเอง ใช้ตัวเลขที่ผู้ใช้ให้ หรือตัวเลขที่ไม่ต้องอ้างอิง เช่น "3 ขั้นตอน" หรือ "5 นาที" ถ้าเป็นข้อมูลจริงที่ไม่แน่ใจ ให้บอกผู้ใช้ว่าควรตรวจ
- ห้ามใส่ชื่อ แบรนด์ หรือหน้าคนจริงที่ผู้ใช้ไม่ได้ให้มา
- ภาษาพูดง่ายๆ ประโยคสั้น ฮุกต้องทำให้อยากดูต่อใน 3 วินาทีแรก

### 3. ดูภาพตัวอย่างก่อนเรนเดอร์
```bash
node make.mjs --style 25 --story my-clips/<ชื่อ>/story.json --still 2.5 --out my-clips/<ชื่อ>/look-hook.jpg
node make.mjs --style 25 --story my-clips/<ชื่อ>/story.json --still 6   --out my-clips/<ชื่อ>/look-list.jpg
node make.mjs --style 25 --story my-clips/<ชื่อ>/story.json --still 10  --out my-clips/<ชื่อ>/look-stat.jpg
```
เปิดดูรูปทั้ง 3 (Read รูป) ถ้าตัวหนังสือล้น ตัวเล็กเกิน หรือสระ/วรรณยุกต์ซ้อนกัน ให้ย่อข้อความแล้วดูใหม่ ห้ามข้ามขั้นนี้

### 4. ทำเสียง + เรนเดอร์ (คำสั่งเดียว)
```bash
sh clip.sh my-clips/<ชื่อ> 25
```
- ทำเสียงด้วย `tools/voice.py` (ใช้ ElevenLabs ถ้ามี key ใน `.env` ไม่งั้นใช้ edge-tts ฟรี) แล้วเรนเดอร์เป็น `my-clips/<ชื่อ>/<ชื่อ>-25.mp4`
- ไม่เอาเสียงพากย์: `sh clip.sh my-clips/<ชื่อ> 25 --no-voice`
- แก้บทแล้วอยากทำเสียงใหม่: ลบโฟลเดอร์ `my-clips/<ชื่อ>/voice` ก่อน แล้วรันใหม่
- อยากได้หลายสไตล์จากบทเดียว: รัน `clip.sh` ซ้ำโดยเปลี่ยนเลขสไตล์ (เสียงใช้ของเดิม ไม่เสียเงินเพิ่ม)
- ใช้เวลาประมาณ 1–3 นาทีต่อคลิป ให้ timeout ยาวพอ

### 5. ส่งงาน
บอกผู้ใช้: ไฟล์อยู่ที่ไหน ใช้สไตล์อะไร ความยาวเท่าไร และถ้าเสียงพากย์อ่านคำไหนแปลกให้บอกได้ ห้ามโพสต์หรืออัปโหลดคลิปไปที่ไหนเอง

## คำสั่งเต็มของ make.mjs (เผื่อต้องการมากกว่า clip.sh)

```bash
node make.mjs --list                                                     # รายชื่อ 50 สไตล์
node make.mjs --style 25 --story s.json --vo voice/ --out clip.mp4       # คลิปเต็ม มีเสียงพากย์
node make.mjs --style 25 --story s.json --out clip.mp4                   # คลิปเต็ม มีแต่เพลง
node make.mjs --style 25 --story s.json --scene stat --dur 4 --out x.mp4 # คลิปแทรก 1 ฉาก ไม่มีเสียง
node make.mjs --style 25 --story s.json --scene list --wide --out x.mp4  # คลิปแทรกแนวนอน 1920x1080
```
ตัวเลือก: `--scene hook|list|stat` (คลิปแทรก), `--dur <วิ>` (ความยาวคลิปแทรก ค่าเริ่ม 4), `--audio` (คลิปแทรกมีเพลง+เสียงเอฟเฟกต์), `--no-music` (คลิปเต็ม มีแต่เสียงพูด), `--wide` (แนวนอน), `--size 720x1280` (ย่อขนาด), `--still <วิ>` (ภาพนิ่ง 1 เฟรม), `--label` (แปะเลขสไตล์มุมจอ)

## กฎการทำงาน
1. เก็บงานทุกอย่างไว้ใน `my-clips/` ห้ามเขียนไฟล์ลงใน `engine/`
2. ห้ามแก้ไฟล์ใน `engine/` เพื่อแก้คลิปเดียว ถ้าจะเพิ่มสไตล์ใหม่ ให้คัดลอก `engine/films/lib50/styles/keynote.js` เป็นชื่อใหม่ เพิ่มบรรทัดใน `engine/films/lib50/styles.txt` แล้วทดสอบด้วย `--still`
3. ห้ามพิมพ์หรือคัดลอกค่าใน `.env` ออกมาให้เห็น
4. ห้ามโพสต์คลิปเอง ส่งไฟล์ให้ผู้ใช้

## แก้ปัญหา
- "headless browser ... not installed" → รัน `sh setup.sh` หรือตั้ง `PLAYWRIGHT_CHROME` เป็นที่อยู่ Chrome
- "cannot run python3" หรือ import error ใน `mix50.py` → รัน `sh setup.sh`
- "needs ffmpeg 7 or newer" → `brew install ffmpeg` (Mac)
- "unknown style" → `node make.mjs --list`
- ElevenLabs 401 = key ผิด · 402 = เครดิตหมด (ใช้ `python3 tools/voice.py my-clips/<ชื่อ> --provider edge` แทนได้)
