# scrapbook-clip: เรื่องเล่า → คลิปสมุดภาพ 60-90 วิ

ทุกคำสั่งรันจากโฟลเดอร์หลักของ repo · ต้นทุนราว 10 บาท/คลิป (ภาพฉาก ~1 บาท/ภาพ + เสียง) ใช้ key OpenRouter อันเดียว
ตัวอย่างเต็ม: `examples/scrapbook-demo/spec.json`

## ขั้นตอน
1. **เลือกเรื่อง + ตรวจข้อเท็จจริงก่อนเขียน** (ปี ตัวเลข ชื่อคน) ไม่แน่ใจใช้คำว่า "ราว", "เล่ากันว่า", "มีรายงานว่า" · ห้ามแต่งตัวเลข
2. สร้าง `my-clips/<ชื่อภาษาอังกฤษ>/spec.json` (รูปแบบด้านล่าง)
3. `python3 scrapbook/make.py my-clips/<ชื่อ> check` ต้องขึ้น OK ก่อน (ฟรี) แก้จนผ่าน
4. `python3 scrapbook/make.py my-clips/<ชื่อ>` ทำครบในคำสั่งเดียว ได้ `<ชื่อ>.mp4` + `cover.png` + `sheet.jpg`
5. **ตรวจเองก่อนส่งผู้ใช้**: เปิด `sheet.jpg` ดูทุกฉาก (ภาพสื่อผิด? ตัวหนังสือล้นจอ? ตัวละครหน้าเพี้ยน?) แก้ spec แล้วรันคำสั่งเดิมซ้ำ ภาพ/เสียงที่ทำแล้วไม่เสียเงินซ้ำ (อยากได้ภาพใหม่ ลบไฟล์ใน `assets/` ก่อน)

## spec.json
```json
{"title": "ชื่อคลิป",
 "cover": "ฮุกบนปก [คำสีแดง]",
 "images": {"<ชื่อภาพ>": "<prompt ภาษาอังกฤษ คนให้เห็นแค่ด้านหลัง ไม่มีตัวหนังสือ>"},
 "lines": ["บทพากย์ภาษาพูด 8-11 บรรทัด ≈ 60-90 วิ ใช้ ... เว้นจังหวะ ตัวเลขเขียนเป็นคำอ่าน"],
 "long": [1, 4],
 "scenes": [{"from": 0, "bg": "img:<ชื่อภาพ>|wood|mat|grid|paper", "gray": false, "items": [ ... ]}]}
```
- ฉากเริ่มที่บรรทัด `from` จบเมื่อฉากถัดไปเริ่ม · `long` = บรรทัดที่เว้นหายใจยาวก่อนพูด (จุดหักมุม/คำถาม)
- `at: [บรรทัด, "คำที่อยู่ในบรรทัดนั้น"]` = โผล่ตอนพูดคำนั้น (สะกดตรงเป๊ะ) หรือ `at: 0.35` = วินาทีหลังเริ่มฉาก

| item | ฟิลด์ | ใช้ทำอะไร |
|---|---|---|
| `bub` | ข้อความ, `cls:"q"` (บับเบิลคำถามใหญ่), x, y, size | คำถามเปิด/คำพูด |
| `torn` | ข้อความ, `cls:"w\|y\|r"`, x, y, size, rot | ป้ายกระดาษฉีก ขาว/เหลือง/แดง |
| `big` | ข้อความ หรือ "0" + `count`, `pre`, `post`, `cls:"c\|ink"`, size | ตัวเลขใหญ่/นับขึ้น |
| `stamp` | ข้อความ, x, y, size, rot, `boom`, `shake` | ตราประทับแดง |
| `badge` | ข้อความสั้น, `cls:"rd\|bl\|yl\|gr"`, `d`, size | วงกลมตัวเลข |
| `pol` | ชื่อภาพ, x, y, w, h, cap, rot | รูปโพลารอยด์ |
| `line` | `[x1,y1,x2,y2]`, `pins:true` | เชือกแดงเชื่อม |
| `logo` | ชื่อ (ไฟล์ `assets/logo_<ชื่อ>.png`), w, y, bg | โลโก้/ภาพจริง |
| `sticker` | ชื่อตัวละคร (`characters/<ชื่อ>.png`), x, y, w | ตัวละครผู้เล่า |
| `card` | `["บรรทัดเล็ก","บรรทัดใหญ่ <em>คำเน้น</em>"]`, `at2` | หน้าจบ (ฉากสุดท้าย bg paper) |
ทุก item ใส่ `punch:true` ให้กล้องกระแทกได้ · เฟรม 1080×1920 · ตัวหนังสือบนสุด y≈260 ล่างสุด y≈1450

## เปลี่ยนได้ (ใส่ใน spec)
| อยากเปลี่ยน | ใส่ | หมายเหตุ |
|---|---|---|
| เสียงพากย์ | `"voice": "<ElevenLabs voice id>"` หรือ `"voice": "edge"` (ฟรี) | ไม่ใส่ = เสียงชายไทยเริ่มต้น / VOICE_ID ใน .env |
| คำที่เสียงอ่านผิด | `"say": {"AI": "เอไอ", "SME": "เอสเอ็มอี"}` | ซับยังโชว์คำเดิม |
| ความเร็ว | `"speed": 1.2` | ค่าเริ่มต้น 1.1 |
| สไตล์ภาพ | `"image_style": "watercolor illustration"` / `"flat vector illustration"` / `"3D clay render"` / `"black and white vintage photo"` | ค่าเริ่มต้น realistic photo |
| โมเดลภาพ | `"image_model": "google/gemini-3.1-flash-image"` | ชัดกว่า แพงขึ้น ~2 เท่า ค่าเริ่มต้นใช้ตัวถูกสุด |
| เพลง | `"music_volume": 0.2` (0 = ไม่มีเพลง) | ค่าเริ่มต้น 0.12 เบาแทบไม่ได้ยิน |
| ตัวละคร | `{"sticker": "<ชื่อ>", "x": 40, "y": 840, "w": 500, "at": 0.05}` ในฉากแรก | ไม่ใส่ = ไม่มีตัวละคร |
| โฟลเดอร์ตัวละคร | `"char_dir": "/path/to/poses"` | ใช้ชุดตัวละครของตัวเอง |

**สร้างตัวละคร:** `python3 scrapbook/character.py <ชื่อ> "<รูปร่าง ชุด ของในมือ สีหน้า>"` (ราว 1 บาท)
ตัวเดิมเปลี่ยนชุดตามเรื่อง: เติม `--ref characters/<ตัวเดิม>.png` · ทำจากรูป/การ์ตูนของตัวเอง: `--ref <ไฟล์รูป>` · ชุดสีเขียว เติม `--magenta`
**โลโก้จริง:** `python3 scrapbook/logo.py find "<แบรนด์> logo"` → `python3 scrapbook/logo.py my-clips/<ชื่อ> <ชื่อโลโก้> "file:<ชื่อไฟล์>"` แล้วเปิดดูภาพก่อนใช้

## กฎสไตล์
- บรรทัดแรกเป็นคำถาม "รู้ไหมครับ…" + ฉากแรกมีบับเบิลคำถาม `cls:"q"`
- ไม่มีอีโมจิ (check ไม่ให้ผ่าน) · ไม่ใส่เบอร์โทร · ทุกฉากต้องมีของขยับ (punch/shake/stamp)
- โลโก้ใหญ่ (w 600-900) และห้ามผูกกับคำท้ายบรรทัด (จะโผล่ไม่ถึงครึ่งวิ)
- หน้าจบ: `card` บนพื้น paper ปิดด้วยข้อคิดของเรื่อง
- **ห้ามใช้ AI ทำหน้าคนจริง** คนจริงให้เห็นด้านหลัง/เงา หรือภาพจริงสาธารณะจาก Wikimedia Commons
- ทุกคลิปมีปก (`cover.png` = เฟรมแรก ฝังในคลิปให้ TikTok/FB ใช้เป็นปก) ฮุกปกสั้น 2 บรรทัด
- ไม่ทำแบรนด์แอลกอฮอล์/บุหรี่ (กฎหมายไทย) · เรื่องสถาบันใช้ราชาศัพท์ เล่าเป็นกลาง
